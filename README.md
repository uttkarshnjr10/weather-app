# Weather App

A simple and responsive weather application that fetches real-time weather data using the OpenWeatherMap API. It includes a bilingual chatbot (English and Hindi) to answer common weather-related questions.

## Features
- **Weather Lookup**: Search for current weather by city name.
- **Weather Details**: Displays temperature, humidity, wind speed, and weather conditions (like, rain, clear).
- **Advisory Messages**: Shows tips based on weather (like, "Stay hydrated!" for >35°C, "Carry an umbrella!" for rain).
- **Bilingual Chatbot**: Answers weather questions in English and Hindi (like, "What is humidity?", "लू लगना क्या है?").

- **CSS**: Styling with glassmorphism and responsive design.
